# Security

## Scope

This repository contains assurance tooling, documentation, configuration models and laboratory evidence.

It is not a production OpenEMS distribution and does not claim to provide security support for the upstream OpenEMS project.

## Reporting issues

Security-relevant issues in the original scripts or assurance logic contained in this repository may be reported through this repository.

Potential vulnerabilities in OpenEMS itself should be reported through the security or maintainer channels provided by the upstream OpenEMS project.

Do not include credentials, API keys, access tokens or other secrets in public reports.

## Test boundary

The included failure-injection experiments were performed in a controlled simulated environment.

They must not be interpreted as penetration-test results or as evidence that a production deployment is secure.
